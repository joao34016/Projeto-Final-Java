Sistema de Gerenciamento de Clínica Odontológica

Projeto desenvolvido como trabalho final da disciplina de Java, com o objetivo de criar um sistema para gerenciamento de cadastros de uma clínica odontológica.

Sobre o projeto:

O sistema permite cadastrar, consultar, editar, listar e excluir registros de pacientes e dentistas por meio de um menu interativo no terminal.

O projeto foi desenvolvido utilizando conceitos de Programação Orientada a Objetos (POO), buscando organizar os dados e facilitar o gerenciamento das informações.

Funcionalidades:

Cadastrar pacientes: registra nome, ID, idade e plano (particular ou convênio).

Cadastrar dentistas: registra nome, ID, CRO e especialidade.

Listar cadastros: permite visualizar pacientes e dentistas separadamente.

Pesquisar registros: busca informações pelo nome ou ID.

Editar cadastros: permite atualizar os dados dos registros.

Excluir cadastros: remove pacientes ou dentistas cadastrados.
